# AI Disclosure

I used AI agents both chat assistants and a coding agent while building this project. They helped me plan the design write code, unit tests and documentation, debug problems and prepare the web page design, the monitoring dashboards and the setup instructions. I ran every command on my own machine, including the test suite and the DVC pipeline, and I checked the results myself. I also tried the web page, API, Prometheus, Grafana and MLflow by hand and took the screenshots in docs/evidence myself and some of the AI suggestions were wrong or out of date for example a wrong example command and a wrong guess about a fraud score and I corrected them after checking and no cloud services were used.
